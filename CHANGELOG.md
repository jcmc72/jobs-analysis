## How to Track Changes

When you make updates to this repository, please follow this format for commits:

### Commit Message Format
```
[TYPE] Brief description

Longer description if needed.

- Bullet point 1
- Bullet point 2
```

### Commit Types
- `[UPDATE]` - Updated existing analysis or document
- `[ADD]` - Added new content or materials
- `[FIX]` - Fixed errors or clarifications
- `[ORGANIZE]` - Reorganized or restructured content
- `[PREPARE]` - Interview preparation changes

### Example Commits
```
[UPDATE] Master Dashboard with latest role rankings
[ADD] Additional STAR questions library
[FIX] Typos and clarifications in GPS analysis
[ORGANIZE] Reorganized references by role
```
